# 隐私与素材边界

## 主包内容

只包含中性命名的自有实现、固定版本依赖／模型清单、操作说明和测试。模型从公开来源下载安装到使用者自己的缓存，不从发送者电脑复制。私有环境的账号、Key、token、cookie、聊天标识、绝对目录、代理、服务器、日志、原片和参考音色均不进入主包。

运行时凭证仅由使用者在自己的环境中配置。默认文本模型地址为本机回环地址，并不包含账号。远程模型调用需显式授权，转录会发送到所选服务；使用者须自行评估数据敏感性和费用。

## 工作数据不是公开资料

job、缓存、转录、字幕、音频、视频、日志和批准说明可能含私密内容；即使 `.gitignore` 已排除，它们也不因此成为可公开材料。不要直接压缩整个工作目录或把完整运行报告上传问题单。报告前移除路径、源 URL 中的凭证、账号和敏感台词。

## 可选音色与产出

可以另外准备素材包，但必须逐项确认：

- 有权再分发音频／视频及字幕；
- 有权使用参考声音及进行克隆，公开视频不等于声音授权；
- 转录文本不含私密信息且与参考音频准确对应；
- 文件名、可见水印、画面、隐藏字幕／音轨、容器元数据均已审查；
- 附素材来源、许可、允许用途及限制；
- 使用中性角色编号，不暴露个人或内部项目关联。

模型许可不自动覆盖这些素材；也不因能在本机生成，就推定成片可以公开传播。主包默认使用模型预置声线，所以不选私人素材也能开始验证。

## 检查局限

凭证形态扫描、本机秘密值比对和个人标识规则只能降低泄漏风险，不是绝对隐私或法律认证。新增文件、初始化 Git 后的提交／历史、截图及公开账号资料需要重新审核。仓库不能替使用者绕过审批或自动对外发布。
