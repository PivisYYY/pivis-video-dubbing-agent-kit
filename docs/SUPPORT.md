# 支持范围与故障处理

## 当前范围

- 硬件／语音后端：Apple Silicon Mac + MLX。较老 macOS 版本仍受所固定依赖的系统要求限制，不能概括为所有 Mac 均可用。
- Python：安装脚本使用 3.11；版本约束快照为该路线记录，不是跨平台锁文件。
- 内容：单说话人英文源语音 → 完整中文译配；中英同轴字幕，原声垫底。
- 默认声线：公开模型的 CustomVoice 预置声线，不依赖私人素材。预置音色不可推定全部稳定，每个新音色先探针。
- 可选 Base 克隆：需要使用者提供非空 **16 kHz 单声道**参考音频与准确的转录文本。先转换到另外一个文件，不覆盖原件；建议使用清晰、稳定的陈述句材料。公开模型／合成预置声线不等于对任意真人声音获得授权。
- 原声混入、时长、帧和字幕是可检查的程序结果，语义质量、语气、音色自然度和精细观感仍需连续听审与人审。

暂不包含自动多说话人识别／分离、多角色全自动音色分配、Windows/Linux/CUDA/CPU 后端或全平台安装器。不要用单一声线包装成多人已支持。

## 模型和安装

- 权重按 `models.json` 固定 revision 下载，不把模型名或文件存在当作完整性证明。校验必需文件、JSON 配置及权重索引引用的文件，但不是对任意未知模型进行密码学或安全认证。
- 缺文件可由使用者授权重新 fetch；程序不会静默联网或改到另一个版本。缓存若被其他程序裁剪，SDK 也可能判其不完整。
- FFmpeg 缺少 libass 时，不要假称已烧录字幕。按使用者允许的包管理器安装所需构建，或在明确说明只提供可选字幕轨后使用不带烧录的路线。
- 依赖故障在项目 .venv 修复，避免污染使用者的其他 Agent／模型环境。

## 阶段拒绝不是成功

| 证据／错误 | 处理 |
|---|---|
| 文本模型超时／结构不符合 schema | 查后端与模型真实能力；Ollama 原生接口显式控制 think 和 JSON Schema，不靠不兼容的 OpenAI 扩展参数 |
| 英文覆盖或数字不一致 | 对照源词修译文；不删除数字、版本、事实或专名 |
| 语义审校拒绝 | 查看 semantic_review.json；修订后重新审校，不改 approved 标记 |
| TTS 超窗 | 保留原始 WAV 与 rejection.json，检查素材、声线、真实采样率、分组和自然表达；不得放宽 1.10 倍上限或截掉内容 |
| 中文 ASR 与目标不符 | 对同一最终 WAV 检查独立识别；不能用预期稿提示 ASR 来骗过匹配 |
| 字幕边界切进同一 ASR 词 | 改语义短句边界，不按字数摊时间 |
| 文件／证据哈希不符 | 先查变化来源，不篡改 checkpoint；必要时建新 job |
| 全片缺批准样片／合同不符 | 等使用者实际确认，再记录批准；换原片、模型或音色要重做样片 |

同输入重跑应新增 0 条 TTS；字幕短句边界调整且合并口播不变时，重用原音频与 ASR 词边界。真正修改口播的组才需要重新合成。

## 验收分层

1. **执行完成**：各阶段退出成功，文件存在。
2. **机器检查**：哈希、实际采样率、全量解码、音量、时长、双语轨与词边界证据。
3. **人工检查**：连续听审、画面与字幕布局、语义和音色感受。
4. **使用者确认**：显式记录，只对已确认的媒体与合同有效。

`MACHINE_COMPLETE` 不包含第 3、4 层。短样片通过不证明长视频或所有模型／平台通过。
